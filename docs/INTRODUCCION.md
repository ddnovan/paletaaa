# Mapa completo: ¿Qué he decidido?

## 1. El Producto Software (El "Qué")
Crear una herramienta web interactiva para artistas visuales y diseñadores. Su objetivo es generar paletas de colores estéticas pero que cumplan con las normativas de accesibilidad web (WCAG).

## 2. Filosofía ingenieril
No empezar a picar código ni usar agentes de IA para suprimir al completo el trabajo del proyecto o herramienta. Sino simular un ciclo de vida del software con:

* Gestión: Repositorio, usar GitHub Projects (tablero Kanban) e Issues para simular historias de usuario.
* Control de versiones: Ramas por features y Pull Requests autofirmadas para un historial limpio.

## 3. Arquitectura técnica (El "Cómo")
* Stack: HTML5, CSS3, JavaScript (ES6+), manipulación de DOM y WAI-ARIA 1.1.
